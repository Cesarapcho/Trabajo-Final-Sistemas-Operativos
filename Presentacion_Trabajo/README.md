## Presentación Web

Este módulo contiene la presentación interactiva desarrollada en HTML, CSS y JavaScript para exponer el proyecto de simulación de algoritmos de planificación de CPU.

La presentación resume los fundamentos teóricos, el problema abordado, la implementación de los algoritmos FCFS, SJF, Round Robin y Prioridades, además de mostrar diagramas de Gantt, gráficos comparativos, diagramas UML y de flujo, resultados obtenidos y conclusiones del proyecto.

También incorpora un simulador interactivo que permite visualizar el comportamiento de los algoritmos de planificación mediante una interfaz dinámica y de fácil comprensión, convirtiéndola en una herramienta de apoyo para la demostración y explicación del funcionamiento del sistema.
