# Simulación de Algoritmos de Planificación de CPU

Este repositorio contiene el desarrollo completo del trabajo final del curso de **Sistemas Operativos**, cuyo propósito es diseñar, implementar y analizar un simulador de algoritmos de planificación de CPU utilizando **Python**.

El proyecto permite estudiar el comportamiento de los algoritmos **First Come First Served (FCFS)**, **Shortest Job First (SJF)**, **Round Robin (RR)** y **Planificación por Prioridades**, comparando su desempeño mediante métricas de rendimiento, diagramas de Gantt y gráficos estadísticos que facilitan la comprensión de cada estrategia de planificación.

Además del código fuente del simulador, el repositorio incluye el informe de investigación, la documentación técnica, diagramas UML y de flujo, la presentación web utilizada para la exposición del proyecto y otros recursos desarrollados durante el proceso de implementación.

Este proyecto tiene un enfoque principalmente académico y didáctico, sirviendo como material de apoyo para el aprendizaje de los conceptos fundamentales de planificación de procesos en sistemas operativos y el análisis comparativo de distintos algoritmos de asignación de CPU.
